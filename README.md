# Aurora City — мобильная игра с друзьями

Первая игровая версия (прототип). Открывается в браузере телефона или компьютера. Дизайн, код и анимации разработаны для этого проекта. Названия компаний и цены недвижимости взяты со скриншота, который предоставила заказчица; фирменные логотипы не используются.

## Как поиграть без установки

Откройте файл `aurora_city_offline.html` из архива или отдельно в браузере. Выберите режим, укажите ник и нажмите **«Играть с ботами»**. Работают броски кубиков, покупки улиц, аренда, здания, залоги, бесплатные кейсы, бафы, кредиты и боты. Сохранение делается в браузере автоматически.

## Как включить игру с друзьями по ссылке

На компьютере с Node.js 18+ в папке проекта:

```bash
npm start
```

Откройте `http://localhost:3000` на этом компьютере. Для друзей с других телефонов нужен публично доступный HTTPS-адрес (разместите проект на Node-хостинге с поддержкой WebSocket, например Render или Railway). После размещения откройте адрес, нажмите **«С друзьями и ботами»**, скопируйте ссылку/код комнаты и отправьте друзьям. В ожидании начала игры создатель комнаты выбирает число ботов от 0 до числа свободных мест. Можно играть вместе людям и ботам: например, 2 человека и 2 бота. В режимах «Расклад» и «Перестановка 3» всего должно быть ровно три участника, включая ботов. Друзья заходят по ссылке и присоединяются к той же партии.

**Примечание:** состояние комнат сохраняется в `rooms-data.json`, но на хостинге без постоянного диска сохранения могут пропасть при перезапуске. Для надёжного публичного сервиса понадобится постоянное хранилище. Для полноценного публичного релиза нужны аккаунты, база данных и тестирование безопасности. Нельзя просто открыть HTML-файл на телефонах друзей и ожидать сетевую игру: нужен WebSocket-сервер.

## Режимы этой версии

- **Обычная:** два кубика, свободная покупка, аренда.
- **Быстрая:** два обычных кубика и дополнительный особый (числа, автобус или M1), больший начальный капитал.
- **Ретро:** базовая версия с двумя кубиками.
- **Расклад:** вся покупаемая недвижимость распределена между тремя игроками в начале партии, дополнительный особый кубик.
- **Перестановка 3:** клетки переставлены случайным образом, дополнительный особый кубик.

Режимы ориентированы на идею Monopoly One, но **правила реализованы в упрощённом виде** (не являются точной копией). Проценты аренды, условия улучшения, состав событий и третий кубик пока авторские, не дословно оригинальные. Интерфейс первого релиза рассчитан на максимум пять игроков и приватные комнаты, без рейтинга и подбора случайных соперников.

## Прокачка улиц

Любую купленную улицу можно улучшать в свой ход сразу после покупки, **без сбора полной цветовой группы**. Доступно пять уровней зданий; каждое следующее повышение увеличивает арендный доход. После покупки автоматически открывается карточка улицы с кнопкой «Улучшить». Улучшение недоступно для заложенной улицы и при нехватке денег.

## Анимации

3D-кубики с вращением и падением, перемещение фишек, свечение клеток, денежные монеты и вспышки при покупке, рост здания, открытие кейса с кольцом и частицами, применение карточек усилений, визуальные денежные события, пульсация неона, подсветка активного игрока, появление модальных карточек, микровибрации (если поддерживаются). Звуковые эффекты отключены по умолчанию. В настройках можно включить звуки, выключить вибрацию, выбрать упрощённые анимации.

## Файлы

- `index.html` — основа сайта.
- `style.css` — оформление и анимации.
- `engine.js` — игровая экономика и правила, общие для клиента и сервера.
- `app.js` — интерфейс, локальная игра и синхронизация.
- `server.js` — WebSocket-комнаты для сетевой игры.
- `ws-lite.js` — встроенная поддержка WebSocket без сторонних библиотек.
- `package.json` — запуск серверной части, без внешних зависимостей.
- `aurora_city_offline.html` — автономная версия для игры против ботов.

## Подготовка к публикации

В архив добавлены `render.yaml`, `Procfile`, `.gitignore` и тест `npm test`. Пошаговые инструкции по размещению на Node.js-хостинге находятся в `КАК_ОПУБЛИКОВАТЬ.txt`. Публикация статической HTML-версии не включает игру с друзьями — для неё нужен сервер.

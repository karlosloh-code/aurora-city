AURORA CITY — ПУБЛИКАЦИЯ САЙТА

В архиве — полноценный Node.js-сайт с WebSocket-комнатами. Простой статический хостинг (Netlify Drop, GitHub Pages, ship.page) подходит только для игры с ботами: он НЕ умеет запускать этот сервер и соединять игроков.

Вариант с бесплатным тарифом: Render (https://render.com)
1. Создайте репозиторий на https://github.com/new (можно приватный).
2. Распакуйте ZIP и загрузите ВСЕ файлы из архива в корень репозитория (Add file → Upload files → Commit changes). Не загружайте ZIP как единственный файл.
3. Откройте https://dashboard.render.com → New → Web Service.
4. Выберите репозиторий с игрой. Для сервиса укажите:
   Language/Runtime: Node
   Build Command: npm install --omit=dev
   Start Command: npm start
   Instance Type: Free (если доступен)
   Health Check Path: /healthz
5. Нажмите Deploy Web Service. Когда состояние станет Live, откройте публичный адрес *.onrender.com.
6. В игре создайте комнату, выберите число ботов, отправьте ссылку друзьям. В одной комнате могут быть и люди, и боты.

Никаких подключений к ChatGPT для этих шагов не нужно. Но для публикации на Render необходима регистрация на платформе и размещение кода в доступном ей репозитории.

Вариант без GitHub: хостинг с загрузкой ZIP и поддержкой Node.js/WebSocket (например, Hostinger Node.js). Обязательно выбирайте Node.js web app, а НЕ static site. Установите команду запуска npm start. Условия и цена хостинга зависят от выбранного тарифа.

Временное ограничение бесплатного Render: сервис засыпает после периода неактивности; после перезапуска комнаты и сохранения на локальном диске могут быть потеряны. Для долговременного сохранения понадобится база данных или постоянный диск.

ПРОВЕРКА: https://<ваш-домен>/healthz должен показывать {"ok":true,"rooms":0} (число комнат может быть другим).

ТЕКУЩАЯ ВЕРСИЯ: пять режимов реализованы по мотивам игры, не идентичны правилам Monopoly One. Основные действия проверены, но перед постоянным использованием нужна дополнительная проверка игровых сценариев на разных телефонах.
